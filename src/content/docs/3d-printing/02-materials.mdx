## Material Types
### Filaments
| Filament | Purpose & Notes  |
| -     |         -        |
| PLA | The default. Easy to print, stiff, and good detail. Use it for prototypes, models and most general parts. It softens at low temperatures (about 55–60°C), so don’t use it for anything that will get hot, like a part left in a car or near a motor. It’s a bit brittle. |
| PETG | Tougher and slightly flexible, with better heat and chemical resistance than PLA. Good for functional parts that need to take some impact. It can string a little and may need a bit more cleanup. |
| ABS | Handles heat well (about 100°C) and is tough. Good for functional parts and enclosures. It warps on big flat parts and gives off fumes while printing. It can be glued or smoothed with acetone. |
| ABS-GF | Glass-fiber-filled ABS. Stiffer, holds its shape better and warps less than plain ABS, with a matte finish. It’s a bit more brittle. Use it for brackets, mounts and parts that need to stay rigid. |
| TPU | Flexible and rubbery. Use it for grips, bumpers, gaskets, feet and cases. It prints slowly, and very thin parts can be hard to get right. |
| PVA | Water-soluble support material. Use it as support for PLA (or PETG) when there are complex overhangs or internal cavities you can’t reach to remove support. Dissolve it in water afterward. It’s very moisture-sensitive, so keep it dry. |
| Support for PLA | Breakaway support material for PLA. Used as the support interface layer, it gives much cleaner surfaces under overhangs and peels off easily. It’s not water-soluble. |
| Support for ABS | Breakaway support material for ABS, which gives clean undersides on ABS parts. Same idea as Support for PLA. |
| Nylon (sometimes available) | Very tough and wear-resistant. Good for gears, hinges and parts that rub or flex repeatedly. It absorbs moisture fast, so it must be dried, and it can warp. |
| PPA-CF | MPI request only. Carbon-fiber-reinforced nylon (polyamide). Very strong and stiff, with high heat resistance. Use it for high-load or high-temperature mechanical parts, like robot parts or motor mounts. It’s expensive and has to be dried before printing. |

### Resins
| Resin | Purpose & Notes  |
| -     |         -        |
| White/Gray Resin | Normal, no special properties |
| Tough 2000 | Use when a part needs have high strength. Can be baked during curing for additional strength (select 70 degree option on the Form Cure) |
| Fast Model Resin | Very fast print times, useful for minis/models that don’t need to be strong |
| Clear Resin | Transparent, can turn slightly yellow after curing |
| Flexible 80A Resin | Flexible, ours is translucent |
